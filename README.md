# VidBriefs (2.0)

COMP3000 Final Year Project; Alfie Nurse

**Supervisor:** Dr Amir Aly

## Vision

VidBriefs (2.0) is made for people who wish to consume the video's insights efficiently without having to watch the entire video. Basically: 1) find the relevant parts first, 2) put the best ones on top for the user, 3) let the AI respond using only those parts, 4) keep learning from what the user does and keep checking it is still getting it right as their interests transition.
